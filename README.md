# LBNL SD-AHU screening plots

Interactive plots of the LBNL simulated single-duct air-handling-unit dataset: operating mode,
APAR rules, expert rules, and which rule sets flag each occupied 15-minute window.

One page per raw data file, plus `index.html` which links to all of them. The plots are generated by
`restart/plot_step03_modes_apar.py`; the pages here load the plotting library from a CDN, so they
need an internet connection.

## Publishing these pages with GitHub Pages

1. Create an empty repository on GitHub, for example `sdahu-plots`, without a README.
2. From this folder (`restart/publish`), run:

   ```bash
   git init
   git add .
   git commit -m "Interactive screening plots of the LBNL SD-AHU dataset"
   git branch -M main
   git remote add origin https://github.com/USER/REPO.git
   git push -u origin main
   ```

3. On GitHub, open **Settings → Pages**, set **Source** to *Deploy from a branch*, branch `main`,
   folder `/ (root)`, and save.
4. After a minute the pages are live at:

   ```
   https://USER.github.io/REPO/index.html
   https://USER.github.io/REPO/AHU_annual.html
   https://USER.github.io/REPO/coi_stuck_075_annual.html
   ```

5. In `restart/report/main.tex`, set the base address once:

   ```latex
   \newcommand{\ploturl}{https://USER.github.io/REPO}
   ```

   Every figure caption in the report then links to the live page.
